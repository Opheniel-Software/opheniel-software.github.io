What to know before the first release

The Windows preview targets 64-bit Windows and is unsigned. The manager needs .NET Framework 4.8; the editors need the Visual C++ x64 runtime. Mac previews target macOS 13 or later and have not been tested on Mac hardware or notarized.

The current manager installs from local packages. Online downloads and updates are not yet enabled.

A SMALL, INDEPENDENT PROJECT

Built with care.
With credit where it’s due.

Opheniel Software is an independent software project, starting with a calmer desktop office suite. Its focus is simple: useful tools, local files, and a little more room to think.

Opheniel Docs, Sheets and Slides build on WordCraft, GridCraft and DeckCraft by the ArtCraft Team and their contributors. Their work and required notices remain part of the story.
